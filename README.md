# Folio — Criador de CV

Editor de currículos numa única página HTML, com modelos de apresentação, pré-visualização, importação/exportação de dados e impressão em PDF pelo navegador.

## Utilização

Abra `index.html` no navegador, preencha os dados e utilize a opção de impressão para guardar como PDF. Não é necessário instalar um servidor.

## Tecnologias

HTML5, CSS3, JavaScript e JSON. Utiliza Google Fonts, que requer ligação à Internet para carregar as fontes externas.

## Notas

- Os exemplos incluídos na versão pública são fictícios. O ficheiro JSON pessoal e as versões de teste não estão incluídos.
- A função experimental de tradução automática faz uma chamada direta à API Anthropic e **não funciona como tradução pública pronta a usar** sem integração/autenticação adequada. Não introduza chaves API no código frontend; para disponibilizar a função, seria necessário um backend seguro.
- Para gerar PDF, use a função de impressão do navegador e escolha «Guardar como PDF».

Projeto pessoal demonstrativo.
